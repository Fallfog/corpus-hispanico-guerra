# Cola editorial

Archivo de fichas todavía no publicadas. Esta carpeta no se incorpora a la web. La publicación se realiza **únicamente por indicación expresa del titular** después de comprobar investigación, fuentes, acta de revisión y criterios editoriales. No existe un calendario automático activo. Para comprobar el estado real, consultar los JSON de la cola, `editorial/publications.json`, `editorial/config.json` y las ejecuciones de GitHub Actions.
